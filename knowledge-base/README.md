# CleftPath — Medically Verified Knowledge Base

This directory houses curated clinical guidelines, ACPA family resources, NHS care pathways, and pediatric feeding protocols that are indexed into PostgreSQL `pgvector` for PathGuide RAG retrieval.

## Contents
* `/acpa-guidelines/`: American Cleft Palate-Craniofacial Association clinical milestones & family guides.
* `/feeding-protocols/`: Evidence-based specialty bottle instructions (Dr. Brown's, Pigeon, Haberman).
* `/surgical-pathways/`: Standardized surgical timeline and post-operative recovery guidelines.
