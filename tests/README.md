# CleftPath — Root Test Directory

This directory is designated for cross-service end-to-end (E2E) tests (Playwright) and system-wide integration verification.

* **Backend Unit & Integration Tests:** Located in `backend/tests/`
* **Frontend Component & Hook Tests:** Located in `frontend/src/`
* **AI Safety Benchmarks:** Located in `ai-service/tests/` and `backend/tests/test_ai_safety.py`
