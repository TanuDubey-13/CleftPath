## 2. Core Non-Negotiable Rules

### 2.1 Medical Safety & AI Boundaries
1. **Never Diagnose or Prescribe:** The AI assistant (**PathGuide**) and speech tools must never diagnose conditions (e.g. *fistula*, *VPI*, *malocclusion*) or prescribe medications/dosages. Always reinforce the role of the patient's accredited cleft team.
2. **Emergency Escalation:** Preserve the `[EMERGENCY_TRIGGER]` detection system for acute respiratory distress, choking, post-op bleeding, and high fever.
3. **Evidence Grounding:** All health answers generated by PathGuide must cite verified sources from the Health Library or ACPA guidelines.

### 2.2 Privacy & Synthetic Data Policy
1. **Zero Real Patient Data:** NEVER commit, paste, or test with real patient names, medical record numbers (MRNs), hospital records, or personal photos. Always use synthetic test fixtures (e.g., *"Baby Leo"*, *"Parent Sarah"*).
2. **Zero Hardcoded Secrets:** Never commit `.env` files, API keys, JWT secrets, or cloud credentials.
3. **No Direct DB Access from Frontend:** The React frontend must NEVER communicate directly with PostgreSQL or external cloud services without passing through the authenticated FastAPI gateway.

## 3. Engineering Conventions

### 3.1 Backend (Python / FastAPI)
* **Async by Default:** All database operations, external API calls (Gemini, S3), and route handlers must use `async`/`await`.
* **Pydantic v2:** Use `BaseModel` with explicit type annotations for all request/response DTOs.
* **SQLAlchemy 2.0:** Use `Mapped[...]` and `mapped_column(...)` declarative syntax.
* **Tenant Isolation:** Every database query affecting patient data MUST include a filter verifying ownership against `current_user.id` or explicit clinician delegation.
* **Error Handling:** Raise standard `HTTPException` with structured error codes matching `docs/API.md`.

### 3.2 Frontend (React / TypeScript)
* **Strict TypeScript:** No `any` types. All API payloads must share type definitions matching backend schemas.
* **Server State:** Use TanStack Query (`useQuery`, `useMutation`) for all server interactions. Do not store server data in global client stores.
* **Design System & Palette:** Adhere strictly to the warm, supportive visual identity:
  * Warm Ivory background (`#FAF7F2`)
  * Deep Teal primary (`#0F4C5C`)
  * Soft Sage Green (`#81B29A`)
  * Warm Coral accent (`#E07A5F`)
  * Rounded cards (`rounded-2xl` / `rounded-3xl`) with gentle shadows.
* **Accessibility:** Use semantic HTML, ARIA labels on custom interactive widgets, and keyboard navigability.

## 4. Subagent Task Delegation Matrix

When working with autonomous subagents:
* **`research` Subagent:** Use for inspecting library documentation, ACPA guidelines, or verifying scientific literature.
* **`self` Subagent (Isolated):** Use for isolated refactoring, generating extensive test fixtures, or writing comprehensive unit tests without cluttering the main conversation thread.

## 5. Definition of Done for New Features

Before marking any module or pull request complete:
1. Pydantic request/response schemas created and documented.
2. FastAPI router registered under `/api/v1/`.
3. SQLAlchemy model mapped with Alembic migration generated.
4. Tenant isolation authorization test implemented in `tests/`.
5. TypeScript interfaces and React Hook Form components wired with TanStack Query.
6. Linting, type-checking, and unit tests passing (100\% pass rate).
